## 2025-08-29 - Material Icons Ligature Accessibility and Focus Rings
**Learning:** Icon-only buttons using Material Icons ligatures (e.g., `<span class="material-icons-round">play_arrow</span>`) present an accessibility issue. If the span doesn't have `aria-hidden="true"`, screen readers may read the literal ligature text ("play arrow") instead of a proper label. Without an `aria-label` on the button itself, the button lacks accessible context. Furthermore, omitting `:focus-visible` styles makes keyboard navigation difficult for visually impaired or keyboard-only users.
**Action:** When using Material Icons ligatures in icon-only buttons, always apply an `aria-label` to the parent `<button>` element and set `aria-hidden="true"` on the icon `<span>`. Additionally, ensure global or component-level `:focus-visible` styles (such as `outline: 2px solid var(--hover-color)`) are implemented to clearly indicate focus state during keyboard navigation.
